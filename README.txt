Troizy Visuals — Fabric 1.20.1

Сборка через GitHub:
  1) Замени project.zip в репозитории на новый (или залей все файлы вместе с папкой .github)
  2) Вкладка Actions -> Build mod -> дождись зелёной галочки
  3) Внизу страницы запуска в Artifacts скачай troizy-visuals (внутри jar)

Установка: jar в папку mods + Fabric Loader 0.14.21+ и Fabric API (1.20.1).
Меню: Right Shift. Зум: удерживай C (меняется в настройках управления).
Название визуалов: Settings.java -> NAME.

Шрифт: Poppins Bold (SIL Open Font License), лежит в assets/visuals/font/ui.ttf.
Если текст стоит чуть выше/ниже, поправь "shift" в assets/visuals/font/ui.json,
если слишком мелкий/крупный — "size".
